CCH Studio — Platform Overview

What exists, where to click, and the rules that must never be gotten wrong. The read-first reference for the team and for Claude.

C-Team · Aug 12, 2026 · grounded against the live build

01What CCH Studio is

Cindy Holloway's luxury residential interior design platform. Staff work in Studio (cch-platform.web.app); clients use a lighter Client Portal. Everything runs on Firebase.

Flow: Inspire → select products → boards → proposal → client approves (often line by line) → invoice → client pays → purchase orders → vendor bills → QuickBooks.

05Client Portal — what clients see

URL: client.html#/clientview/{projectId} — no password, link access.

Clients CAN see

  • Home, Messages, Notes, Updates, Decisions
  • Inspiration Boards, Room Boards
  • Proposals, Invoices, Documents
  • Tasks (client-visible), Activity, Time & Progress, Client Pepper

Clients NEVER see

  • Purchase orders, vendor bills
  • Cost, markup, margin, DNET
  • Product Library, Smart Time ledger
  • QuickBooks, internal notes

Invoices may show hours/rates if Cindy toggled display on that invoice (default off).

06Rules you must not get wrong

The seven that matter

  1. Doc numbers: PRO-3000+, INV-6000+, PO-9000+. "IN-10000" is old Houzz imports, not the Studio series. There is no DOC financial series.
  2. Products on documents are COPIES. Changing the Product Library does not update existing proposals/invoices. A line edit stays on that document.
  3. Partial approval is normal. A client approves some lines → those become an invoice → the rest stay open. One proposal → many invoices.
  4. POs happen after the invoice is paid — not when the proposal is approved.
  5. PO lines lock when the PO is sent to the vendor. (Invoices lock when sent / paid / overdue / QB-synced.)
  6. QuickBooks syncs both ways — Studio pushes documents out and pulls paid status back. QB is the source of truth for payment.
  7. Timely sync uses production Studio only — never staging.
